# Imágenes de proceso

Dejá acá las fotos que usa la landing. Se muestran con tratamiento duotono
(componente `DuotoneImage`), así que da igual el color original: se ven como un
sistema y **no** como "acá está nuestra planta". Usá tomas de detalle
(manos, cajas, etiquetas, herramientas) — no naves ni líneas completas.

Fuentes válidas: stock con licencia (Unsplash / Pexels sirven), o fotos propias
de detalle. Nunca presentar una foto de stock como instalación de XCAIL.
